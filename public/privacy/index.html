Privacy

This notice describes the NotionFlow developer preview, including its website and document workspace. Contact for privacy questions: contact@notionflow.app.

Documents and drafts

Your text, selected files and edits stay in the current browser tab until you ask the app to process a document or save a draft in Notion. The saved example does not call Claude. Live processing sends the selected source and output type to our server and then to Anthropic's Claude API. PDF files are sent as document input.

The document editor does not store drafts or access codes in a database, browser local storage or cookies. The password-protected debug site uses a secure session cookie, valid for up to 24 hours, to remember preview access. Refreshing clears the editor, but does not delete content already saved in Notion. Our hosting and API providers may keep operational records.

Service providers

Cloudflare hosts the website and API and may process IP addresses, request metadata and security logs. Anthropic processes document content sent for live generation under its applicable API terms and policies.

Notion

Importing a page reads content the configured integration can access. Publishing sends the reviewed report, including task excerpts, to the configured Notion destination. This preview writes to the NotionFlow demo workspace, operated by NotionFlow, rather than your personal workspace. We can see content saved in this demo workspace. It stays there until removed. To request removal, email contact@notionflow.app with the page link. Creating a page does not automatically make it publicly viewable. Notion's policies govern its handling of that content.

The Notion token stays on the server. Visitors do not need to enter a Notion token. This version does not connect to visitors' own Notion accounts.

Access codes and logs

The app sends your preview access code to our API to authorize protected requests. It keeps the code only in the current tab. API requests use the Authorization header. API keys and integration tokens are kept server-side. Application code does not intentionally log source documents or access credentials. Hosting and API providers may retain operational data according to their policies and account settings.

Exports and contact

Markdown and JSON downloads are generated in your browser. You decide where to store or share them. Contact links open your email application; messages you send contain whatever information you choose to include and may be retained to respond to your request.

Analytics and your choices

This preview has no application analytics, advertising scripts or theme cookies. Avoid uploading confidential or personal information during testing unless you are authorized to share it with the relevant providers. You can clear the local draft by reloading. To remove a result saved in our demo workspace, contact us with its page link.

Changes

We will revise this notice if accounts, persistent storage, additional providers or a public Notion connection are introduced.
