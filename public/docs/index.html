WORKSPACE GUIDE

Using NotionFlow

NotionFlow turns documents into team notes, project briefs and work assignments. Claude writes a draft. You can check and edit it before downloading or saving it in Notion.

DocumentClaude draftYour reviewExport / Notion

Start with the saved example

The Harbor Studio example uses sample notes and a saved draft. The source field is locked in this mode. Its summary, decisions and tasks were prepared in advance, not generated from a live Claude call. Change the output view, edit the saved draft and download it without an account.

Use your own document

Select “Your document” and enter the preview access code provided by NotionFlow. Paste 30–30,000 characters, upload a TXT/Markdown file, or upload a PDF of at most 1 MB. Keep PDF tests to about 10 pages. PDF content goes directly to Claude for document reading; NotionFlow does not perform local OCR.

Meeting notes focus on decisions and actions. Project briefs focus on scope and constraints. Task lists focus on assignments and unresolved requirements. All three use the same editable document structure.

Check what was extracted

Task and decision excerpts from text input are matched against the source. Unmatched items are omitted and reported. Even when an excerpt matches, Claude may misunderstand it or assign the wrong date. PDF excerpts require manual comparison with the original. The summary and open questions also need your review.

If the notes do not name an owner or give a date, those fields should stay blank. Check dates carefully when the original wording is ambiguous.

Edit and export

Edit the title, summary, decisions, task names, owners, dates and open questions. Markdown is suitable for manual import or pasting into Notion. JSON includes the draft, processing mode and available model/usage metadata; it marks edits made after generation. Browser downloads do not send the report to another service.

Connected Notion pages

Select a destination: your workspace or the demo sandbox. Choose My Notion workspace, enter your preview access code, and select Connect Notion. Notion asks which pages to share. After returning, select Load shared pages and choose the parent for new drafts. Loading shared pages uses your Notion session; it does not need the preview access code again. Creating a Claude draft and publishing still need that code. You can import pages your selected connection has permission to read. Imports cover rich-text blocks, up to 100 blocks, three nesting levels and 30,000 characters. The app tells you when content is skipped or a limit is reached. Database rows are not imported as page text.

Save a draft in Notion

With an access code, choose the destination, review the draft, check the confirmation box and choose “Create Notion page”. NotionFlow creates a new page; it does not overwrite the source. An optional action-items database stores task names, owners, dates and source excerpts. Results go into the selected workspace. Personal connections never fall back to the sandbox. The result link requires Notion viewing permission; this operation does not make the page public. Use sample or non-sensitive documents.

If publishing reports an incomplete database or a network error, inspect the destination first. A page may already exist. The app does not retry automatically. Submitting the same draft again may create another page.

A recorded Claude-to-Notion test

In a hosted test on October 12, 2026 (UTC), Claude Sonnet 4.6 processed synthetic launch notes and returned two tasks with owners and dates. The API reported 671 input tokens and 248 output tokens. We saved the draft as a new Notion page with two task entries, then read the page back and matched the summary and task titles. This checks one workflow; it does not establish accuracy for all documents.

What works in this preview

You can try a saved example, edit a draft and download it. An access code enables Claude processing and our Notion sandbox. We have tested the full flow: Claude generated a draft, Notion saved the page and tasks, and we read them back to check the result. Personal-workspace OAuth has also been tested through page selection, publishing and readback. It lasts up to 24 hours; reconnect when it expires or Notion revokes access. Disconnecting keeps existing pages in Notion. Saved document history and processing several documents together are not available yet.
